# J&B Line Cinema 0.3.1 · One stroke, no retracing

Gemini로 만든 그림 또는 직접 올린 이미지로 펜을 떼거나 되짚지 않는 한붓 드로잉 아트 영상을 만드는 **빌드 없는 정적 웹앱**입니다. GitHub Pages에 파일을 올리면 실행됩니다. React, npm 설치, CDN, 별도 서버가 필요하지 않습니다. 이미지 생성 시에만 Gemini 서버와 통신합니다.

## 0.3.1 이미지 생성 400 오류 수정

v1 `generationConfig.responseFormat.image`는 표시 문자열이 아닌 enum 값을 요구합니다. 이전 버전이 `"9:16"`과 `"1K"`를 그대로 보내던 오류를 수정했습니다.

| 화면 설정 | v1 REST 요청 값 |
| --- | --- |
| 9:16 | `ASPECT_RATIO_NINE_BY_SIXTEEN` |
| 16:9 | `ASPECT_RATIO_SIXTEEN_BY_NINE` |
| 1:1 | `ASPECT_RATIO_ONE_BY_ONE` |
| 1K | `IMAGE_SIZE_ONE_K` |

Preview의 v1beta `imageConfig`에는 기존 문자열을 보냅니다. Cloudflare Worker도 같은 방식으로 수정했고, 이전 웹앱의 문자열 입력과 새 enum 입력을 모두 받습니다. Worker를 사용 중이면 별도로 재배포하세요. `index.html`과 `js` 파일을 함께 교체하고 새로고침하면 화면 상단에 **03.1**이 표시됩니다.

공식 규격: https://ai.google.dev/api/generate-content#ImageResponseFormat

## 빠른 시작: GitHub Pages

1. ZIP을 풀고 `line-cinema` 폴더 **안의 파일들**을 GitHub 저장소의 루트에 올립니다. 저장소 첫 화면에 `index.html`, `style.css`, `js`, `assets`가 보여야 합니다.
2. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
3. 브랜치는 **main**, 폴더는 **/ (root)**로 지정하고 Save를 누릅니다.
4. 배포된 `https://아이디.github.io/저장소이름/`으로 접속합니다.
5. **연결 설정 → Gemini API 키 → 설정 적용**을 누릅니다. ‘이 브라우저에 API 키 저장’은 기본으로 켜져 있습니다.
6. 설명을 쓰고 **그림 생성하기 → 재생 → 영상 저장** 순서로 사용합니다.

`index.html`을 더블클릭하는 `file://` 실행은 지원하지 않습니다. JS 모듈과 Worker 때문에 HTTP/HTTPS로 열어야 합니다. 로컬에서 확인하려면 이 폴더에서 `python3 -m http.server 8080`을 실행하고 `http://localhost:8080`으로 접속하세요. Windows에서는 `py -m http.server 8080`도 가능합니다.

## 먼저 비용 없이 확인하기

**예시 체험**을 누르면 첨부 참고 영상의 완성 장면으로 드로잉/카메라/출력을 확인할 수 있습니다. API 키가 필요하지 않습니다. 직접 이미지 불러오기, 선 추출, 연출 변경, PNG/SVG/영상 출력도 API를 호출하지 않습니다.

예시 이미지 `assets/reference-study.jpg`는 사용자가 제공한 영상 73초 장면입니다. 화면 원작자 표기는 **@crisd.singleline**입니다. 작가의 새 작품이나 앱 자체가 생성한 그림으로 표시하지 않습니다. 공개 서비스에서 자체 예시로 대체하려면 같은 경로의 이미지를 교체하고 `app.js`의 예시 출처 문구도 변경하세요.

## 요청하신 세 가지 동작

| 기능 | 구현 |
| --- | --- |
| 손으로 그리는 듯한 선 | 중심선의 작은 래스터 잡음을 정리한 뒤 모든 선을 정확히 한 번씩 지나는 경로를 만듭니다. 펜 들기·공중 이동·되짚기는 없습니다. 기존 선을 다시 지나는 대신 새 연결선을 실제로 그립니다. 필압과 속도가 계속 변하고 내부 구간 경계에서도 위치·굵기·시간이 이어집니다. 필압은 절차적 시뮬레이션입니다. |
| 정체를 늦게 드러내는 카메라 | 기본은 아래쪽의 작은 부분부터 그립니다. 연속 경로를 따라 이동하는 펜을 완만하게 따라갑니다. 처음은 약 3.6배 확대, 그리면서 약 1.85배까지 풀리고, 마지막 공개 구간에서 전체를 보여줍니다. 고정 화면/부드러운 추적도 선택할 수 있습니다. |
| 마지막 선화만 3초 | 드로잉 시간 뒤 4초 동안 전체를 공개합니다. 이 구간에서 밑그림이 완전히 사라집니다. 이후 정확히 3초 동안 흰 바탕과 완성된 검은 선만 고정 표시합니다. 펜촉도 사라집니다. |

**드로잉 시간은 목표값입니다.** 선의 전체 길이와 출력 fps에 맞춰 프레임당 이동 거리를 제한하고 필요한 경우 시간을 늘립니다. 펜촉이 지나간 부분만 조금씩 늘어납니다. 예시 이미지의 기본 30fps 설정은 드로잉 72초 + 전체 공개 4초 + 완성 선화 3초 = 총 79초입니다. 구간마다 멈추거나 획을 새로 시작하지 않습니다. 필압 0은 굵기 변화를 끕니다. ‘손의 리듬’은 미세한 흔들림과 곡률에 따른 속도 차이에 영향을 줍니다.

**v0.3의 핵심은 한붓 경로 1개, 펜 들기 0회, 같은 선 되짚기 0회입니다.** 각 선을 한 번만 쓰는 경로를 계산하며, 같은 두 점을 잇는 다른 선을 추가할 때에도 기존 선과 겹치지 않는 새 경로를 만듭니다. 단순 교차점은 다시 지날 수 있지만 선을 따라 되돌아가는 동작은 허용하지 않습니다. 완성 경로의 실제 좌표도 검사해 길이를 가진 중복 선분을 발견하면 되짚기로 대체하지 않고 오류를 표시합니다.

모든 그림이 원래 상태 그대로 한붓 그리기가 가능한 것은 아닙니다. 갈림길과 분리된 윤곽이 많은 그림에는 **새 연결선이 추가되어 최종 선화가 달라집니다.** 사진에서 선을 추출할 때 생긴 3px 이내의 작은 교차점 덩어리를 정리하고, 가지에 붙은 2.5px 이하의 짧은 잡음을 제거합니다. 주요 윤곽은 유지하되 픽셀 단위로 원본과 같지는 않습니다. Gemini에는 처음부터 두 끝점만 있는 한붓 구성, 되짚기 금지, 막힌 가지 금지, 작은 세부 묘사 단순화를 요청합니다. 실제 생성 결과의 품질을 보장하지는 않습니다.

기존 `.linecinema` 프로젝트도 열면 새 경로를 계산합니다. v0.1 추출 결과의 짧은 교차점까지 복원하려면 ‘선 다시 추출’을 누르세요.

## 생성 방식과 API 사용

- **그림 + AI 선화:** 이미지 생성 요청 2회. 원본 그림을 만든 다음, 같은 구도를 유지하면서 핵심 윤곽만 남기는 선화를 Gemini에 요청합니다. 참고 영상처럼 선택된 간결한 선을 얻는 기본 방식입니다.
- **선화만 생성:** 이미지 생성 요청 1회. 밑그림부터 흑백 선화이므로 사진을 따라 그리는 느낌은 약해집니다.
- **AI 선화 정리:** 불러온 원본 또는 생성된 원본을 간결한 선화로 변환합니다. 이미지 생성 요청 1회입니다.
- **선 다시 추출:** 현재 선화/원본을 브라우저에서 다시 분석합니다. API를 호출하지 않습니다.

기본 모델은 공식 문서 기준 `gemini-3.1-flash-image`입니다. 계정에서 지원하는 모델 ID를 연결 설정에서 직접 바꿀 수 있습니다. Preview 모델은 호환 요청 형식을 사용합니다. 자동으로 다른 모델을 사용하거나 실패한 요청을 재시도하지 않습니다.

이미지 생성은 계정의 결제/할당량에 영향을 받습니다. 한 번의 요청이 반드시 무료이거나 일정한 가격이라는 보장은 없습니다. API 키는 URL이 아닌 `x-goog-api-key` 헤더로 전송합니다. 실제 사용자 키가 없으므로 제작 과정에서 유료 Gemini 생성 요청은 실행하지 않았습니다. 요청/응답/오류 처리는 모의 응답으로 검증하며, 공식 문서를 기준으로 연결했습니다.

AI가 원본을 선화로 다시 그릴 때 위치가 조금 달라질 수 있습니다. 원본과 선화의 픽셀 단위 정합을 보장하지 않습니다. 어긋남이 보이면 밑그림 농도를 낮추거나 ‘선화만 생성’을 사용하세요. 일반 사진의 로컬 윤곽 추출은 객체의 의미를 이해하지 않으므로 잔선이 많을 수 있습니다. 선 추출 조절에서 종류·세부 묘사를 조정하거나 AI 선화 정리를 사용하세요.

## 출력과 저장

- 9:16, 16:9, 1:1 / 1080p·720p / 30·24·18 fps.
- WebCodecs H.264를 지원하면 **MP4를 프레임 단위로 인코딩**합니다. 화면 녹화가 아니므로 이 경로에서는 선택한 fps와 정확한 프레임 수를 보존합니다.
- 지원하지 않으면 MediaRecorder로 실시간 녹화합니다. 브라우저가 MP4를 지원하면 MP4, 아니면 **WebM**으로 저장합니다. 실시간 방식은 기기 부하에 따라 프레임이 빠질 수 있습니다. 탭을 바꾸면 불완전한 파일 대신 녹화를 중단합니다.
- 1080p 출력은 데스크톱의 최신 Chrome/Edge 사용을 권합니다. 모바일은 메모리·인코더 지원에 따라 차이가 있으며, 720p로 낮추면 부담을 줄일 수 있습니다.
- 기본 출력은 **무음**입니다. 손이나 팔의 실사 영상은 합성하지 않습니다. 표시되는 것은 작은 펜촉입니다.
- PNG: 흰 배경과 최종 선화. SVG: 필압 굵기를 반영한 실제 벡터 면 경로.
- `.linecinema` 프로젝트: 원본, AI 선화, 추출 경로, 프롬프트, 연출 설정을 담습니다. API 키나 비밀번호는 포함하지 않습니다.
- 마지막 프로젝트는 IndexedDB에 자동 저장됩니다. 브라우저 데이터 삭제·시크릿 모드·저장 공간 정책의 영향을 받으므로 중요한 작업은 프로젝트 파일로 보관하세요.
- API 키는 요청하신 대로 이 브라우저의 localStorage에 보관할 수 있습니다. **암호화된 비밀 저장소가 아닙니다.** ‘저장된 키 삭제’로 지울 수 있습니다. 같은 GitHub Pages origin의 다른 앱과 저장 영역이 공유됩니다. 코드나 저장소에 키를 넣지 마세요.

## 나중에 Cloudflare 비밀번호 방식으로 전환

`cloudflare/README.md` 순서대로 별도 Worker를 배포하면 됩니다. 웹앱은 이미 **연결 설정 → Cloudflare · 비밀번호** 모드를 지원합니다. API 키는 Worker Secret에 보관하고, 웹앱에는 Worker 주소와 접속 비밀번호만 입력합니다. 현재는 배포하지 않은 준비 코드입니다.

## 회귀 검사
